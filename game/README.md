# Game files

Retail game files are intentionally not included in this repository.

To build this project, place the supported Xbox 360 executable at:

```text
game/Default.xex
```

Expected SHA-256:

```text
0bb765d0c89de2674efea76056a9c1b6236173587398ddc248b08cc1a6092883
```

To run the game, preserve the original extracted disc layout below `game/`.
The current launcher expects at least `SAW2GAME/CookedXenon/` and uses the
original case-sensitive filenames.

Use files from your own legally obtained copy. Do not commit or redistribute
retail executables, assets, archives, keys or other copyrighted game data.
